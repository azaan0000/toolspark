Quick answer

Glassmorphism is a frosted-glass UI effect built from four ingredients: a translucent background (e.g. bg-white/10), backdrop-blur for the frost, a subtle light border, and a soft shadow. This generator gives you all four as ready Tailwind classes with a live preview.

How the tailwind css glassmorphism generator works

Glass = translucent tint + backdrop-filter: blur() + light 1px border + soft shadow  ·  Tailwind: bg-white/10 + backdrop-blur-xl + border border-white/20 + shadow-2xl

Glassmorphism (the term was coined by Michal Malewicz of Hype4) works when a translucent surface sits over a colorful background and blurs it. Three practical rules make it look right:

  • There must be something to blur. Glass over a flat white page looks like a gray box. Put it over a gradient, photo or colorful mesh.
  • Keep tint low (5–15% opacity). The blur does the work. Above ~30% opacity it becomes a plastic card, not glass.
  • Add a light border. A 1px white border at ~30% opacity simulates the glass edge catching light — this is what separates 'glass' from 'fog'.

The generated Tailwind arbitrary values work in both Tailwind v3 and v4. If you only use white tints, you can shorten to standard classes like bg-white/10 backdrop-blur-xl rounded-2xl border border-white/20 shadow-2xl.

Frequently asked questions

Does backdrop-filter work in all browsers?

It works in all modern browsers (Chrome, Edge, Firefox 103+, Safari 9+ with the -webkit- prefix). The generated CSS includes the -webkit- prefix. On very old browsers the card degrades to a translucent box — still readable, just not frosted.

Tailwind v3 or v4 — do these classes work?

Yes. The output uses arbitrary-value classes like bg-[rgba(...)] and backdrop-blur-[16px], which both v3 and v4 support. For plain white-glass you can swap to the shorter utility classes (bg-white/10, backdrop-blur-xl) instead.

Why does my glassmorphism look washed out?

Usually the background behind it is too light, the tint opacity too high, or blur too strong. Try 5–12% opacity, 12–24px blur, and place the card over a vivid gradient like the preview here.
