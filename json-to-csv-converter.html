How the json to csv schema converter works

Column set = union of all keys (nested objects flattened as parent.child)  ·  Cell = escaped string (quotes doubled, delimiters wrapped)  ·  Row = one JSON object

CSV needs one flat table; JSON is a tree. The converter bridges that gap in three steps:

  • Row detection: a root array becomes rows directly. A root object is scanned for the largest array of objects (like orders above) and that becomes the rows.
  • Schema flattening: nested objects flatten into dotted columns (customer.email), so no data is lost. Arrays of primitives join with "; ", deeper arrays stay as JSON strings.
  • Escaping: values containing the delimiter, quotes or newlines are quoted and escaped — so Excel, Google Sheets and pandas read the output correctly.

The detected schema shows every column the converter found — useful before you import data anywhere. A root object wraps into a single row.

Frequently asked questions

Is my JSON uploaded anywhere?

No. Parsing, flattening and CSV generation all happen in your browser with plain JavaScript. The tool works even if you go offline after loading the page — nothing is sent to any server.

How are nested objects handled?

Nested objects are flattened with dot notation (e.g. customer.address.city), which keeps every value as its own CSV column. Arrays of simple values are joined with semicolons; arrays of objects are kept as JSON strings so you can process them downstream.

Does it handle JSON Lines or API responses?

Yes — paste any API response. If the root is an object containing an array (a very common API shape), the tool automatically uses the biggest array of objects as the rows, and the rest still converts as a single-row fallback.
