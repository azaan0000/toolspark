How the free fire color code generator works

Colored bio = [RRGGBB] + your text, per colored part  ·  e.g. [FF0000]RED [00FF00]GREEN [FFFF00]YELLOW

Free Fire renders hex color codes inside square brackets in the profile bio/signature. The code is the six-digit hex value without the hash — the same system used in web colors:

  • [FF0000] red · [00FF00] green · [0000FF] blue · [FFFF00] yellow · [00FFFF] cyan · [FF9000] orange · [BF00FF] purple
  • Each [code] + text pair colors that part of the bio. The next bracket switches the color again.
  • Codes go in the bio/signature field (Profile → edit). Nicknames have stricter character limits and most name fields don't render color codes — bio is where this works.

Tip: keep the bio short. Long bios get truncated on the profile card, and too many color switches hurt readability.

Frequently asked questions

How do I add a colored bio in Free Fire?

Open your profile, tap the edit (pencil) icon, open the bio/signature field, paste the code you copied here (e.g. [FF0000]DRIFT [FFFF00]KING) and save. The bracket codes render as colors on your profile.

Do color codes work in Free Fire nicknames?

The name field has stricter character limits and generally does not render color codes — the reliable place is the bio/signature section. Keep the name simple and put the styling in the bio.

Why is my color code showing as plain text?

Check the brackets are square [ ] not round ( ), the code is exactly six hex characters, and you saved the bio after pasting. Copy-pasting from a source that converted brackets to full-width characters (Japanese-style （）) is the most common cause.
